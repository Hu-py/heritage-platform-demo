# 上海文物真实数据平台
公开发布真实文物位置、评分、描述和风险几何。RAG/LLM 尚未接入。

数据规模：763 处文物、20,304 条细项评价、449 个含几何的风险单元。使用 gzip 静态文件，由现代浏览器解压加载。坐标、指标分组和缺失值处理沿用本地版。全部数据公开可下载。

注：全市 1,570,826 个建筑轮廓（7,719 个空间分块，约 15GB）体量过大，未包含在 GitHub 公开版中，建筑轮廓图层在网页上显示提示。原始 GIS 与表格保存在本地源目录。

原始 GIS 与表格保存在本地源目录，网站发布经过转换的文物评价结果；未匹配记录见 audit.json.gz 统计。
